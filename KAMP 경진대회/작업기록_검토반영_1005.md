## 1. 반영 여부 판단
| 검토 의견 | 판단 | 반영 내용 |

| 모든 분할에서 그룹 겹침 검증 | 반영 | `split_audit.csv` (홀드아웃·외부 CV·내부 3-fold·블록), 코드 내 assert |

| 무작위 그룹 CV = 피드백 운영 성능 표현 수정, 과거→미래 검증 추가 | 반영 | 검증 3종 표로 구분, expanding-window 대리 검증 추가 (`forward_cv.csv`) |
| 단일 클래스 구간 N/A·사유 기록 | 반영 | CV·블록 CV·과거→미래·제품별 비교 모두 표본 수·불량 수·사유 기록 |
| 개발/테스트 상수 열 각각 제거 위험 | 반영 | 입력 열을 개발셋에서 정해 테스트·추론에 고정 적용 (`feature_columns`) |
| 테스트 재사용 한계 명시 | 반영 | 노트북·README 에 '재사용 평가' 명시, 테스트 결과로 설정 변경 없음 |

## 2. 기존 저장 결과 vs 수정 후 실행
| 항목 | 기존 저장 결과 | 수정 후 실행 (정식, 깨끗한 출력 폴더) |
|---|---|---|
| 최종모델 | ExtraTrees / process+cavity | ExtraTrees / process+cavity (변화 없음) |
| dev / test 행 수 (불량) | 1917 (34) / 476 (8) | 1909 (34) / 484 (8) — 교차 짝 24쌍 이동 |
| 무작위 사출 그룹 CV PR-AUC (전체/CN7/RG3) | 0.139 / 0.270 / 0.079 | 0.121 / 0.258 / 0.083 |
| CV Recall@20% | 0.707 | 0.700 |
| 생산순번 블록 CV PR-AUC (8 / 16블록) | 0.048 / 0.060 | 0.045 / 0.060 |
| 과거→미래 대리 검증 | 없음 | CN7 평가 불가(N/A), RG3 구간별 PR-AUC 0.026~0.063 |
| 테스트 PR-AUC (전체/CN7/RG3) | 0.353 / 0.698 / 0.017 | 0.343 / 0.674 / 0.017 |
| 테스트 공통 임계값 / F1 | 0.359 / 0.400 | 0.052 / 0.067 |
| 테스트 RG3 Recall / Recall@20% | 0 / 0 | 0 / 0 |
| 가중치 없음 vs 가중치 PR-AUC | 0.144 vs 0.139 | 0.127 vs 0.121 (보정 t p=0.66) |
| 행 단위 vs 그룹 CV (ET) | 0.198 vs 0.139 | 0.184 vs 0.121 |

- CV PR-AUC 하락(0.139→0.121): 같은 개발셋에서 병합 전/후 그룹으로 ET 를 비교하면 0.155 → 0.121 이었다. 다만 반복별 평균이 0.07~0.22 로 흔들려, 누수 제거 효과와 fold 배정 변동을 정확히 분리할 수 없다.
- 테스트 F1 0.400 → 0.067: 공통 임계값이 0.359 → 0.052 로 바뀐 영향이다. 불량 34건으로 정한 임계값이 그룹 정의만 바뀌어도 크게 변한다는 뜻이며, 고정 임계값 대신 상위 k% 운영을 택한 근거다.

## 3. 실행·검증 범위
- 정식 실행: `python run_all.py --clean` (Python 3.12.7, Windows 11, 6,133초) → 오류 없음, 분할 점검 7종 통과
- 축소 실행(`--quick`)은 코드 점검용으로만 사용했고 수치를 보고하지 않음
- 노트북: `jupyter nbconvert --execute --inplace` 로 전체 실행, 오류 0, 셀 순서 실행, 노트북-저장 결과 일치 5종 통과
- `predict.py` 로 저장 모델 추론 확인
- **KAMP-NOTE 에서는 이번 수정 코드를 실행하지 않았다** (이전 버전만 확인). 제출 전 KAMP-NOTE 에서 `python run_all.py` 재확인 필요.
